# Conglomerate icon overlay

The folder assets in this overlay are color-modified derivatives of the Yaru
icon theme, version 26.04.5.1ubuntu-1 as installed when this overlay was made.
Yaru is published by Canonical Ltd. and contributors under GPL-3.0. This
overlay is distributed under the same license; see `LICENSE-GPL-3.0.txt`.

Only folder assets are included. All other icons are inherited from the
installed `Yaru-yellow-dark` theme.
