# Conglomerate Chromium theme

This Manifest V3 theme uses champagne gold for the tab strip and inactive
tabs, near-black for the active tab and toolbar, ivory text, and gold toolbar
icons. Load this directory as an unpacked extension in Chromium.

The theme follows Chromium's official theme-extension manifest format. The
packaged CRX can be installed locally; its signing key is intentionally kept
outside Git.
